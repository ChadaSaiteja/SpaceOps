SpaceOps is a free, open-source disk analyzer for Windows. A high-speed Rust scanning engine maps every byte on your drive into an interactive treemap, finds developer clutter across 8 ecosystems, and routes every cleanup through the Recycle Bin so nothing is ever gone for good.

What it detects

Built for people whose disks fill up silently

Gigabytes disappear into virtual disks, build caches, and forgotten virtual environments. SpaceOps shows exactly where, and why.

⚙

Parallel Rust Scanner

Rayon-backed traversal using Win32 FindFirstFileExW, measuring true 4 KB cluster-allocated size instead of misleading logical bytes.

▦

Accelerated Treemap

Squarified layout via the Bruls-Huizing-van Wijk algorithm, rendered with Direct2D at 60–120 FPS. Double-click to drill into any directory.

🔨

8 Ecosystems Tracked

Node.js, Rust, .NET, Python, Java, Docker/WSL, Git, and IDE caches — plus dormancy flags for projects untouched 30+ days.

🛡

Zero-Accident Cleanup

An immutable blacklist guards system paths. All deletions flow through Shell COM to the Recycle Bin, with a dry-run mode that touches nothing.

🔍

Sub-5ms Search

Query indexed trees instantly with structured filters: ext:log, size:>1GB, type:dir, or combinations.

🗃

Incremental Sync

SQLite WAL persistence restores trees in under 100 ms, with NTFS USN Journal resync reading change records in under 50 ms.

Questions

Frequently asked questions

Is SpaceOps free?

Yes. SpaceOps is MIT-licensed open-source software. There is no paid tier, no telemetry, and no network access — it runs entirely offline on your machine.

Will SpaceOps delete my files permanently?

No. Every deletion routes through the Windows Shell COM API to the Recycle Bin, so you can restore anything. C:\Windows, C:\Program Files, boot manager paths, and user system profiles are hard-blocked and can never be removed, even in execution mode. A dry-run mode reports reclaimable space without touching the filesystem.

Is it safe to run while I have projects open?

Yes. The scanner treats directory junctions, symlinks, and volume mount points as leaves, so it never double-counts or traverses outside your drive. Reparse points are detected and displayed rather than followed.

How is this different from WinDirStat, TreeSize, or WizTree?

SpaceOps is free and open source, uses a hardware-accelerated Direct2D treemap instead of slow GDI rendering, holds a 1M-node tree in roughly 55 MB of RAM, detects developer clutter across 8 ecosystems that competitor tools ignore, and supports incremental resync via the NTFS USN Journal instead of a full rescan.

What are the system requirements?

Windows 10 version 1809 or later, or Windows 11, on x64 or ARM64. To build from source you also need the .NET 9 SDK, Rust 1.75+, and Visual Studio 2022 Build Tools with the Desktop C++ workload.

Does it need internet access?

No. SpaceOps is 100% local with zero telemetry. Once built, it never makes a network request.

Get started

Build from source

# 1. Clone the repository
git clone https://github.com/ChadaSaiteja/SpaceOps.git
cd SpaceOps

# 2. Build the Rust core and WinUI 3 app
./storage-intelligence/scripts/build.ps1 -Configuration Release

# 3. Launch
& ".\storage-intelligence\app\StorageIntelligence\bin\Release\net9.0-windows10.0.19041.0\win-x64\StorageIntelligence.exe"
