A WinDirStat alternative for Windows

SpaceOps is a free, MIT-licensed treemap disk analyzer for Windows that you can use instead of WinDirStat, especially if you want developer-cache detection (node_modules, Rust target, WSL disks) and cleanup routed through the Recycle Bin. WinDirStat is a long-established, mature tool, so SpaceOps is a newer option rather than a proven replacement.

Updated 2026-10-16 · SpaceOps v0.x · Windows only

How does SpaceOps compare with WinDirStat?

Both tools show disk usage as a treemap. The table sticks to facts that are easy to verify; for anything about WinDirStat, check its official site for the current version, because tools change over time.

When might SpaceOps suit you better?

  • Your disk fills with developer artifacts such as node_modules, Cargo target/, .venv or WSL ext4.vhdx, and you want them identified and sized by type.
  • You want undoable cleanup: every deletion goes through the Windows Shell to the Recycle Bin.
  • You prefer a WinUI 3 interface that follows Windows light and dark mode.

When should you stay with WinDirStat?

  • You want a tool with many years of field use and a large user base.
  • You need something other than Windows 10 1809 or later, or Windows 11.
  • You cannot accept an unsigned v0.x build yet.

How do I try SpaceOps?

  1. Get the zip from the latest release (or build from source if none is published).
  2. Verify the SHA-256 checksum, unzip anywhere and run it.
  3. Scan a drive and compare the treemap with what you already know.
  4. Use the dry run to preview any cleanup before confirming.

Frequently asked questions

Is SpaceOps a drop-in replacement for WinDirStat?

Not necessarily. SpaceOps covers the treemap-based disk usage view and adds developer-cache detection, but it is a young v0.x project. Try both and keep the one that fits your workflow.

Is SpaceOps free like WinDirStat?

SpaceOps is free and MIT licensed. For WinDirStat's current licensing, check its official site.

Does SpaceOps work on Windows on ARM?

Yes, an ARM64 build is planned as part of each release alongside x64.

Can I undo a deletion made with SpaceOps?

Yes, restore it from the Recycle Bin. Windows may permanently delete items too large for the Recycle Bin, so check its size limit before large cleanups.
