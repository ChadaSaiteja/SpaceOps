# Implementation Phase Planning Prompt

The architecture for this component has been approved.

Now create the implementation plan.

Do NOT write the complete implementation.

Break the work into small phases.

For each phase define:

- Objective
- Requirements
- Files/modules affected
- Interfaces
- Data structures
- Dependencies
- Implementation tasks
- Tests
- Acceptance criteria
- Performance criteria
- Error cases
- Security considerations
- Documentation updates
- Definition of done

Each phase should be independently testable.

Do not combine unrelated features.

At the end, provide the recommended implementation order.

Wait for my approval before moving to the next phase.
