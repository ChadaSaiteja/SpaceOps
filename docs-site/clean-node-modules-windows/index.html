How to clean node_modules folders on Windows

A node_modules folder is safe to delete when its project still has package.json (and ideally a lockfile), because npm, pnpm or yarn can recreate it with an install. SpaceOps finds every node_modules folder on a drive, shows its size, flags projects untouched for 30 days or more, and sends your selection to the Recycle Bin.

Updated 2026-10-16 · SpaceOps v0.x · Windows only

Why does node_modules take so much space?

Each JavaScript or TypeScript project installs its own dependency tree, and abandoned projects keep that tree forever. Across many old projects it can add up to many gigabytes; SpaceOps' developer-storage reference lists Node.js targets as a high-impact category (node_modules, npm cache, pnpm store, yarn cache).

How do I clean node_modules with SpaceOps?

  1. Scan the drive that holds your projects.
  2. Search for node_modules size:>500MB to list the largest ones first.
  3. Check dormancy: projects untouched for 30+ days are flagged; active projects default to unchecked.
  4. Dry run to preview the files and bytes that would be reclaimed without touching anything.
  5. Confirm the selection. Folders move to the Recycle Bin, and source code and git history are not touched.
  6. Restore later if needed: run npm install (or your package manager's install) in a project to rebuild its dependencies.

How do I list node_modules manually in PowerShell?

This lists paths only; it does not measure sizes. Replace the folder with your projects directory.

Get-ChildItem -Path C:\code -Directory -Filter node_modules -Recurse -Force -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty FullName

Before you delete: make sure the project has a package.json. A folder named node_modules without one may be something else. Windows can also refuse or permanently delete items too large for the Recycle Bin, so check its size limit before a very large cleanup.

What about the package manager caches?

The global npm cache, pnpm store and yarn cache are re-downloaded on demand, so they are also reclaimable. Clean them with the package manager's own cache commands, or let SpaceOps show how large they are first.

Frequently asked questions

Is it safe to delete node_modules?

Generally yes when the project has a package.json, because an install recreates the folder. Your source code and git history are not inside node_modules.

Will I lose uncommitted work?

SpaceOps only targets artifact folders such as node_modules, never working source files. Still, review the dry-run list before confirming.

Why are active projects unchecked by default?

Projects modified in the last 30 days are likely in use, so SpaceOps highlights them but leaves cleanup unchecked.

Does SpaceOps delete node_modules permanently?

No. Items go to the Recycle Bin through the Windows Shell, so you can restore them.
