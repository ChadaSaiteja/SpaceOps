# Performance Engineering Prompt

Design the performance strategy for the application.

Primary concern:

Fast analysis of large Windows drives containing millions of files.

Define measurable targets for:

- Initial scan
- Directory traversal
- Metadata collection
- Tree construction
- Database writes
- Search
- Treemap rendering
- Memory usage
- UI responsiveness
- Incremental updates

Identify bottlenecks.

Define benchmarks and representative test datasets.

Do not optimize based on assumptions.

Measure first, then optimize.
