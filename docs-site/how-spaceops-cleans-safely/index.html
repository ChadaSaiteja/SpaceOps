How SpaceOps cleans your disk safely

SpaceOps cleans safely by analyzing first and deleting last: protected system paths are hard-blocked, a dry run previews exactly what would be reclaimed, every deletion goes to the Windows Recycle Bin so it can be undone, and nothing runs without your explicit confirmation.

Updated 2026-10-16 · SpaceOps v0.x · Windows only

What are the safety layers?

  1. Immutable system blacklist: the Rust core refuses requests that target or resolve into C:\Windows, C:\Program Files, boot and recovery paths, pagefile.sys, hiberfil.sys and user profile roots.
  2. Recycle Bin routing: user cleanups go through the Windows Shell (IFileOperation with undo), not permanent unlinking, so items can be restored.
  3. Dry-run mode: simulates the cleanup, counting files and cluster-allocated bytes and checking permissions without touching the filesystem.
  4. Explicit confirmation: there are no background deletion timers, hidden tasks or silent deletions; every action needs your review.

What does SpaceOps tell me before deleting?

Each candidate shows what it is, where it is and what happens if you remove it, for example that the next build recompiles dependencies while source code and git history stay untouched.

What are the limits?

  • SpaceOps never removes source code files or git metadata; cleanup targets designated artifact folders only.
  • Windows may refuse or permanently delete items too large for the Recycle Bin, so check its size limit for very large cleanups.
  • SpaceOps is v0.x software. Read the full safety model, and report vulnerabilities privately per the security policy.

Frequently asked questions

Can SpaceOps delete Windows system files?

No. Protected locations such as C:\Windows and C:\Program Files are hard-blocked in the Rust core, even in execution mode.

Can I undo a cleanup?

Yes. Deletions are routed to the Recycle Bin, so restore the items from there.

What does dry run do?

It computes the file count and size that would be reclaimed and validates permissions, without modifying anything.

Does SpaceOps clean automatically?

No. There are no automated background deletions; every action needs your confirmation.
