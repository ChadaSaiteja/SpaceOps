Free disk space analyzer for Windows

SpaceOps is a free, open-source (MIT) disk space analyzer for Windows 10 and 11 that scans your drives and shows what is using space as an interactive treemap. It runs fully offline with no paid tier or telemetry, and every cleanup goes to the Recycle Bin so it can be undone.

Updated 2026-10-16 · SpaceOps v0.x · Windows only

What does SpaceOps do?

SpaceOps answers three questions about a full disk: what is using my storage, why is it so big, and what can I safely do about it. A parallel Rust engine scans the drive and reports true cluster-allocated size, and the results are drawn as a squarified treemap you can drill into.

It is aimed at developers and power users whose disks fill with build artifacts, package caches and virtual disks, and it also works as a general-purpose folder-size viewer.

How do I find what is using my disk space?

  1. Download the zip for your PC from the latest release (x64 or ARM64). If no release is published yet, build from source.
  2. Verify the SHA-256 checksum against SHA256SUMS.txt (a PowerShell snippet is on the download section).
  3. Unzip anywhere and run the app. Builds are unsigned for now, so Windows SmartScreen may warn; see the download notes.
  4. Scan a drive or folder. The treemap fills in as the scan streams results.
  5. Drill down: double-click a tile to zoom in, use the breadcrumb bar to climb out, and click a tile to inspect its path and size.
  6. Search with filters such as ext:iso, size:>1GB or node_modules size:>500MB.

Is it really free, and what are the limits?

Yes: the source is MIT licensed, the app is free to use, and it makes no network requests. The honest limits are that SpaceOps is Windows only, is still version 0.x, and that release builds are unsigned until a code-signing certificate is obtained, so SmartScreen may show a warning. See the changelog for what has shipped.

What else does it detect?

  • Developer clutter across 8 ecosystems: Node.js, Rust, .NET, Python, Java/JVM, Docker/WSL, Git and IDE caches.
  • Dormant projects: folders untouched for 30 days or more are flagged first as cleanup candidates.
  • Junctions, symlinks and mount points are shown but never followed, so nothing is double-counted.

Frequently asked questions

Is SpaceOps free?

Yes. SpaceOps is MIT-licensed open-source software with no paid tier, no telemetry and no network access. It runs entirely offline.

Which Windows versions does it support?

Windows 10 version 1809 or later, and Windows 11, on x64 or ARM64.

Does it delete files on its own?

No. SpaceOps has no background cleanup. Every action needs your confirmation in the UI, and deletions go to the Recycle Bin so they can be restored.

Is the download signed?

Not yet. Builds are unsigned until a code-signing certificate is obtained, so verify the SHA-256 checksum and expect a SmartScreen prompt.
