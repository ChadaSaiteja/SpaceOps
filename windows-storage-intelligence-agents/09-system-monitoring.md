# System Monitoring Design Prompt

Design the system monitoring component.

Potential metrics:

- CPU
- RAM
- Disk
- Network
- GPU
- Battery
- Processes

For each metric identify the correct Windows APIs and data sources.

Design:

- Sampling interval
- Background workers
- Data model
- Aggregation
- UI update frequency
- Resource overhead
- Error handling
- Permission requirements
- Historical data requirements

Keep MVP scope small.

Do not implement until the design is approved.
