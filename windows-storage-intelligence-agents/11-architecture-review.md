# Architecture Review Prompt

Review the proposed design for this component as a senior Windows systems engineer.

Do not write code.

Look for:

- Incorrect assumptions
- Windows API problems
- Rust architecture problems
- Performance bottlenecks
- Memory problems
- Security issues
- Data consistency problems
- Scalability problems
- UX problems
- Future migration problems
- Unnecessary complexity

Compare the proposed architecture against simpler alternatives.

Return:

1. Problems
2. Risks
3. Alternatives
4. Recommended changes
5. Final architecture
6. Remaining questions

Do not optimize for theoretical perfection.

Optimize for a reliable MVP that can evolve.
