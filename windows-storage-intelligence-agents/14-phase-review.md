# Phase Review Prompt

Review the completed implementation against the approved design.

Do not add new features.

Check:

- Requirements
- Architecture
- Correctness
- Tests
- Error handling
- Performance
- Security
- Memory usage
- Threading
- Windows compatibility
- Rust safety
- UI behavior

Identify:

PASS
FAIL
NEEDS IMPROVEMENT

For every issue explain:

- What is wrong
- Why it matters
- How it should be fixed

Do not move to the next phase until all critical issues are resolved.
