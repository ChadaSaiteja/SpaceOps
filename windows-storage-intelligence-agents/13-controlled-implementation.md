# Controlled Implementation Prompt

The architecture and implementation plan for this phase have already been approved.

Implement ONLY this phase.

Do not implement future phases.

Do not introduce new architecture without discussing it first.

Follow the approved design.

Before writing code:

1. Restate the phase objective.
2. List the files/modules that will change.
3. Explain the implementation approach.
4. Identify risks.
5. Confirm the acceptance criteria.

Then implement.

After implementation:

- Explain what was changed.
- Provide tests.
- Provide test results.
- Identify anything incomplete.
- Identify technical debt.
- Confirm whether acceptance criteria were met.

Do not silently expand scope.
