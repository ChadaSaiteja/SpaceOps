# Security and Privacy Design Prompt

Design security and privacy for the Windows Storage Intelligence application.

Analyze:

- Filesystem permissions
- Administrator privileges
- UAC
- Protected directories
- File deletion safety
- Path traversal
- Symlinks and junctions
- Malicious filesystem structures
- Installer security
- Update security
- License validation
- Network communication
- Crash reporting
- AI data transmission
- Local database security

Principle:

The application should be local-first and should not upload user filesystem data by default.

Identify threats, mitigations, and security requirements.

Do not implement security-sensitive behavior until the design is approved.
