Verify checksum · PowerShell
# Run in the folder containing the zip you downloaded
Invoke-WebRequest https://github.com/ChadaSaiteja/SpaceOps/releases/latest/download/SHA256SUMS.txt -OutFile SHA256SUMS.txt
$expected = ((Select-String -Path .\SHA256SUMS.txt -Pattern 'SpaceOps-win-x64.zip').Line -split '\s+')[0]
$actual   = (Get-FileHash .\SpaceOps-win-x64.zip -Algorithm SHA256).Hash
if ($actual -ieq $expected) { 'OK: checksum matches' } else { 'MISMATCH: do not run this file' }

Unzip to any folder and run the executable. To uninstall, delete the folder. Cleanup always goes to the Recycle Bin, and SpaceOps makes no network requests.

Capabilities

Everything you need to answer “where did my space go?”

Built for people whose disks fill up silently: virtual disks, build caches, and forgotten environments.

Parallel Rust scanner

Rayon-backed traversal over Win32 FindFirstFileExW, reporting true 4 KB cluster-allocated size, not misleading logical bytes.

Accelerated treemap

Squarified layout (Bruls–Huizing–van Wijk) drawn with Direct2D. Double-click to drill in, use breadcrumbs to climb out.

8 developer ecosystems

Node.js, Rust, .NET, Python, Java, Docker/WSL, Git and IDE caches, with dormancy flags for projects untouched 30+ days.

Zero-accident cleanup

Immutable system-path blacklist, Recycle Bin-only deletion through Shell COM, and a dry-run mode that touches nothing.

Sub-5 ms search

Query indexed trees with structured filters: ext:log, size:>1GB, type:dir, or any combination.

Incremental sync

SQLite WAL snapshots restore trees in under 100 ms; the NTFS USN Journal resyncs changes in under 50 ms, no full rescan.

Frequently asked questions

Is SpaceOps free?

Yes. SpaceOps is MIT-licensed open-source software. There is no paid tier, no telemetry, and no network access — it runs entirely offline on your machine.

Will SpaceOps delete my files permanently?

No. Every deletion routes through the Windows Shell COM API to the Recycle Bin, so you can restore anything. C:\Windows, C:\Program Files, boot manager paths, and user system profiles are hard-blocked and can never be removed, even in execution mode. A dry-run mode reports reclaimable space without touching the filesystem.

Is it safe to run while I have projects open?

Yes. The scanner treats directory junctions, symlinks, and volume mount points as leaves, so it never double-counts or traverses outside your drive. Reparse points are detected and displayed rather than followed.

How is this different from WinDirStat, TreeSize, or WizTree?

SpaceOps is free and open source, uses a hardware-accelerated Direct2D treemap instead of slow GDI rendering, holds a 1M-node tree in roughly 55 MB of RAM, detects developer clutter across 8 ecosystems that competitor tools ignore, and supports incremental resync via the NTFS USN Journal instead of a full rescan.

What are the system requirements?

Windows 10 version 1809 or later, or Windows 11, on x64 or ARM64. To build from source you also need the .NET 9 SDK, Rust 1.75+, and Visual Studio 2022 Build Tools with the Desktop C++ workload.

How do I download and install SpaceOps?

Download SpaceOps-win-x64.zip (or SpaceOps-win-arm64.zip on ARM64 PCs) from the latest GitHub release, optionally verify it against SHA256SUMS.txt with Get-FileHash, unzip it anywhere, and run the app. There is no installer; delete the folder to uninstall. If no release is published yet, build from source.

Why does Windows SmartScreen warn about SpaceOps?

Release builds are unsigned until a code-signing certificate is obtained, so SmartScreen may show an unrecognized-app warning. Verify the SHA-256 checksum against SHA256SUMS.txt, then choose More info and Run anyway only if it matches and you downloaded from the official GitHub release.

Does it need internet access?

No. SpaceOps is 100% local with zero telemetry. Once built, it never makes a network request.
