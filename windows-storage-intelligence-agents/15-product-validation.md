# Product Validation Prompt

Before implementation, validate the product idea.

Analyze:

- Target users
- Jobs to be done
- Main storage problems
- Existing Windows solutions
- Competitors
- Free alternatives
- Paid alternatives
- Differentiation
- Willingness to pay
- Developer audience
- General consumer audience
- Potential pricing
- Distribution
- Risks
- MVP scope

Do not recommend building features simply because competitors have them.

Separate:

- Evidence
- Assumptions
- Hypotheses
- Decisions

End with a clear MVP problem statement and validation plan.
