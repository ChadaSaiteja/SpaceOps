# Windows Storage Intelligence — AI Agent Prompts

This folder contains the prompts used to plan and build the Windows Storage Intelligence application.

## Workflow

1. Start with `00-master-project-manager.md`
2. Discuss architecture before coding.
3. Use the component-specific prompt for each major component.
4. Use `08-architecture-review.md` to challenge the design.
5. Use `09-phase-planning.md` to create implementation phases.
6. Use `10-controlled-implementation.md` only after approval.
7. Use `11-phase-review.md` after implementation.
8. Update the master PRD and architecture documents after important decisions.

## Core rule

Do not implement the whole product at once.

PRD → Architecture → Component Design → Review → Decision → Phase Plan → Implementation → Test → Review → Next Phase.
