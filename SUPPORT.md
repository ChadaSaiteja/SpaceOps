# Support Resources for SpaceOps

Thank you for using SpaceOps! Here is how to find help, ask questions, and report issues.

---

## Where to Get Help

### 1. Found a Bug?
If you encountered unexpected behavior, a crash, or an issue with filesystem scanning:
- Check existing issues in our [GitHub Issue Tracker](https://github.com/ChadaSaiteja/SpaceOps/issues) to see if it has already been reported.
- If not, open a new issue using our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md)**.
- Please include your Windows version, filesystem type (NTFS/ReFS/FAT), and reproduction steps.

### 2. Have a Feature Request?
If you have an idea for a new developer artifact detector (e.g., Python cache, Docker volume), visualization improvement, or new capability:
- Search existing discussions and issues to see if it is already planned.
- Open a **[Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)** outlining the problem, suggested architecture, and safety considerations.

### 3. Have Questions or Need General Discussion?
- For questions about how SpaceOps works, architecture discussions, or setup help, open a thread in [GitHub Discussions](https://github.com/ChadaSaiteja/SpaceOps/discussions).

### 4. Found a Security Vulnerability?
- **Do not open a public issue.** Please review our [Security Policy](SECURITY.md) and report it privately via GitHub Security Advisories or by emailing **saiteja.chada2000@gmail.com**.

---

## Community Guidelines

SpaceOps is an open-source project maintained by volunteers. Please be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md) when engaging with the community.
