# Release and Distribution Design Prompt

Design the Windows release strategy.

Analyze:

- MSIX
- Microsoft Store
- Direct download
- Installer
- Code signing
- Certificate management
- Auto-update
- Rollback
- Crash reporting
- Versioning
- Licensing
- Feature flags
- Beta releases
- Stable releases

Recommend a practical MVP distribution strategy.

Do not implement release infrastructure until the design is approved.
