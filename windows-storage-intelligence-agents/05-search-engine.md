# Search Engine Design Prompt

Design the local search system.

Do NOT write code yet.

The search engine must eventually support:

- Filename
- Path
- Extension
- Size
- File type
- Date
- Directory
- Developer artifacts

Evaluate:

- SQLite search
- In-memory search
- Filesystem search
- Custom index
- Windows indexing APIs
- Future USN Journal updates

Define the MVP search architecture and the future architecture.

Optimize for:

- Speed
- Low memory
- Large datasets
- Incremental updates
- Simple implementation

Define the query model, indexing strategy, result model, ranking, and testing.

Do not implement until the design is approved.
